# 崽崽小看板 · 7 天家庭试用（P4）

目标：连续 7 天用 AD / 钙的日常，看它是不是"比在微信里问更省心"（验收 E1、E2）。

## 开始前（家长，一次）

1. 网页"事项"里只留真实要做的事（AD、钙），时间和家里实际一致。
2. 奶奶手机装好最新安装包，"我是谁"选奶奶，小组件放在桌面第一屏，通知权限允许。
3. 家长自己手机上打开网页，确认能看到同一份看板。

## 每天（1 分钟）

- 不用特意提醒奶奶，照常过日子。
- 晚上打开网页"记录"，看顶上的 **试用复盘**：
  - **及时登记**：计划时间后 1 小时内登记的比例。
  - **一般晚多少分钟**：长期偏晚可以考虑把计划时间往后挪。
  - **没人登记 / 隔天补登 / 撤销**：有数字就记一笔原因（忘了、没看到、点错、日期不对）。
- 当天如果还是在微信里问了"喂了没"，在下面记一次。

遇到问题直接在项目里说，我来修，修好发新安装包，试用不用重新开始。

## 第 7 天复盘

- [ ] E1 七天里没有日期错位（"隔天补登"都有合理原因），没有重复登记。
- [ ] E2 家里觉得比在微信里问更省心。
- 参考：及时登记率、微信里问的次数有没有变少、奶奶是不是自己会看小组件。
